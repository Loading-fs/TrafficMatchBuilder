TrafficMatch Builder v0.6 Beta

Built by simmers, for simmers.

============================================================
WELCOME
=======

TrafficMatch Builder is a lightweight utility for Microsoft Flight Simulator, vPilot and VATSIM users.

The application scans compatible AI traffic libraries, supported addon liveries and Microsoft Flight Simulator Community packages to generate ready-to-use VMR model matching files.

Supported traffic sources currently include:

• FSLTL
• AIG
• Standard traffic libraries
• Fenix A320 Family liveries
• PMDG 737 Family liveries
• PMDG 777 Family liveries

Traffic Library Scanning is recommended whenever possible. Addon Livery Scanning should primarily be used when a desired livery is not already available in a dedicated traffic library such as FSLTL or AIG.

Full-fidelity addon aircraft may require significantly more simulator resources than dedicated traffic models.

============================================================
WHAT IS A VMR FILE?
===================

A VMR file is used by vPilot to decide which aircraft model should be displayed for another pilot on the VATSIM network.

When flying online, vPilot receives information such as aircraft type, airline code, callsign and livery information. It then attempts to match this information with aircraft models installed on your computer.

TrafficMatch Builder helps generate these matching rules automatically.

============================================================
QUICK START GUIDE
=================

1. Launch TrafficMatch Builder
2. Select your preferred language
3. Select your Microsoft Flight Simulator Community folder
4. Select a traffic library or supported addon livery folder
5. Click Scan Models
6. Review the scan report
7. Export the VMR file
8. Import the VMR file into vPilot

============================================================
TRAFFIC LIBRARY SCAN VS ADDON LIVERY SCAN
=========================================

Traffic Library Scan is recommended for most users.

Use it for:

• FSLTL
• AIG
• Other AI traffic model libraries

Advantages:

• Best performance
• Lowest simulator resource usage
• Largest airline coverage
• Most reliable model matching source

Addon Livery Scan is intended for supported full-fidelity addon aircraft liveries.

Currently supported:

• Fenix A320 Family
• PMDG 737 Family
• PMDG 777 Family

Use addon liveries mainly when the desired livery is not already available in your traffic library.

============================================================
SECURITY & PRIVACY
==================

TrafficMatch Builder operates entirely offline.

The application does not:

• Connect to external servers
• Download content
• Modify simulator files
• Modify Windows settings
• Collect personal information
• Require administrator privileges

TrafficMatch Builder only reads aircraft configuration files from folders selected by the user and generates VMR files based on the information found.
